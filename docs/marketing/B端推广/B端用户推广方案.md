## 二、B端销售策略

### 2.1 销售渠道

**渠道一：直销（重点）**
- 目标：本地培训机构（车程1小时内）
- 方式：电话邀约 → 上门演示 → 试用 → 签约
- 优势：关系牢固，回款快，可定制化

**渠道二：渠道代理**
- 目标：有教育行业资源的代理商
- 方式：提供代理价+销售工具包+返点
- 优势：快速覆盖，减轻直销压力

**渠道三：线上获客**
- 目标：全国中小机构
- 方式：官网/B端 landing页 → 免费咨询 → 试用 → 订阅
- 优势：低成本，覆盖面广

---

### 2.2 销售流程SOP

**Step 1：线索收集（每日）**
```
来源渠道：
1. 企查查搜索"英语培训"关键词，获取本地机构名单
2. 教育展会/沙龙收集名片
3. 老客户转介绍
4. 官网B端咨询表单

目标：每日新增10条有效线索
```

**Step 2：初次联系（24小时内）**
```
电话话术：
"您好，我是灵犀AI英语听说的小王。我们是一款AI英语学习工具，
可以帮助您的学员提升英语听力和口语。
我们已经在XX机构试用，效果很好。
方便加个微信发您一份资料看看吗？"

关键：不急于报价，先建立联系
```

**Step 3：需求调研（第一次接触）**
```
了解内容：
- 机构规模（学员数/教师数）
- 当前英语教学痛点
- 预算范围
- 决策流程
- 竞品使用情况

目标：判断是否为有效线索
```

**Step 4：产品演示（第二次接触）**
```
演示内容（15分钟）：
1. 产品定位（2分钟）
2. 核心功能演示（8分钟）
3. 报价方案（3分钟）
4. 答疑（2分钟）

演示材料：
- 演示PPT（见下方模板）
- 演示账号（10个试用账号）
- 客户案例（2-3个）

目标：获得试用意向
```

**Step 5：试用跟进（1-2周）**
```
跟进节奏：
- Day 1：确认试用账号已激活，询问遇到问题
- Day 3：了解使用反馈，解答疑问
- Day 7：收集使用报告，推动决策
- Day 14：最终跟进，促成签约

目标：试用→付费转化
```

**Step 6：签约回款**
```
签约材料：
- 电子合同（支持在线签署）
- 发票（增值税普通发票）
- 激活码清单（Excel格式）

付款方式：
- 支付宝/微信转账
- 银行对公转账
- 分期（首月50%，次月50%）

目标：签约后7天内回款
```
