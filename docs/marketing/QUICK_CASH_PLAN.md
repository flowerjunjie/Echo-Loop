# 🚀 灵犀AI英语听说 - B端快速变现方案

## 一、激活码系统（已完成）

### 架构
```
企业采购 → 管理员生成激活码 → 发给学员/员工 → 
App输入激活码 → 自动开通订阅权益
```

### 已实现的API
| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/activation-codes/generate` | POST | 管理员生成（需X-Admin-Key） |
| `/api/v1/activation-codes/activate` | POST | 用户激活（需JWT） |
| `/api/v1/activation-codes/my-codes` | GET | 查询个人激活记录 |
| `/api/v1/activation-codes` | GET | 管理员查询所有码 |

### Flutter端入口
- **设置页** → 「激活码兑换」入口（始终可见）
- **Paywall页** → 底部「激活码」按钮
- **设置页（开发者选项）** → 「管理激活码」→ 生成/复制/分享

### 套餐类型
| 类型 | API名称 | 月数 | 适用场景 |
|------|---------|------|----------|
| 月卡 | monthly | 1 | 体验/短期 |
| 季卡 | quarterly | 3 | 课程周期 |
| 半年卡 | halfYearly | 6 | 学期 |
| 年卡 | yearly | 12 | 年度订阅 |
