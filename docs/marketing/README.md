## 🚀 快速使用指南

### 给销售团队用
```
先读 → docs/sales/B端销售方案.md
再看 → docs/sales/销售话术手册.md
带着 → docs/marketing/销售演示/B端销售演示大纲.pdf 去演示
```

### 给运营团队用
```
先读 → docs/operations/OPERATION_HANDBOOK.md
日常 → docs/marketing/文案库/全渠道文案库.md（复制即用）
排期 → docs/marketing/内容日历/30天社交媒体内容日历.md
数据 → docs/marketing/数据指标/数据指标定义手册.md
复盘 → docs/marketing/复盘模板/运营复盘模板.md
```

### 给客服团队用
```
标准答案 → docs/marketing/FAQ/常见问题大全.pdf
疑难处理 → docs/marketing/客服话术/客服话术手册.pdf

```

### 给管理层用
```
产品定位 → docs/marketing/产品卖点/产品定位与卖点卡.pdf

```

### 给新用户/新人用
