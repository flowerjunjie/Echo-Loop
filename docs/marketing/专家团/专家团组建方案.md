## 一、专家团定位

### 1.1 什么是专家团？

专家团是由5-7位各领域专业人士组成的顾问团队，
定期对产品提出建议、参与评审、协助推广。

### 1.2 为什么要建专家团？

| 原因 | 说明 |
|------|------|
| 产品方向校准 | 避免闭门造车，确保产品满足真实需求 |
| 专业背书 | 专家推荐增强用户信任度 |
| 资源导入 | 专家带来行业资源和用户渠道 |
| 危机预警 | 提前发现产品风险和市场机会 |

## 二、专家构成

### 2.1 人员结构（5-7人）

| 角色 | 人数 | 要求 | 主要职责 |
|------|------|------|----------|
| 产品专家 | 1人 | 互联网产品总监经验，5年以上 | 产品方向评审、功能优先级建议 |
| 技术专家 | 1-2人 | AI/语音/NLP领域工程师或研究员 | 技术选型评审、性能优化建议 |
| 运营专家 | 1人 | 用户增长/社群运营经验 | 获客策略、裂变方案设计 |
| 市场专家 | 1人 | 教育行业营销经验 | 品牌定位、推广渠道建议 |
| 教育专家 | 1人 | 英语教学/课程设计经验 | 学习内容设计、教学场景建议 |

### 2.2 专家画像示例

**产品专家**：
- 背景：前某教育APP产品总监，带过10万+用户产品
- 资源：熟悉教育类App运营全流程
- 时间：每周可投入2-3小时

**教育专家**：
- 背景：大学英语教师/英语培训机构主讲老师
- 资源：有高校英语教研组人脉
- 时间：每月可参与1次线上评审

## 三、专家权益

### 3.1 权益清单

| 权益 | 具体内容 | 价值 |
|------|----------|------|
| 终身会员 | 产品全部功能终身免费 | ¥268/年 × 终身 |
| 推荐分成 | 专家推荐用户购买，提成10% | 每推荐10人购买≈¥280 |
| 方案采纳奖金 | 建议被采纳，¥200-2000/条 | 激励高质量建议 |
| 年度优秀专家 | 年度表现最佳，¥5000-10000奖励 | 荣誉+物质双重激励 |
| 产品内测权 | 新功能优先体验，反馈意见 | 参与感 |
| 署名权 | 产品"感谢专家"页面展示姓名/头像 | 个人品牌曝光 |

### 3.2 权益计算示例

假设专家A推荐了20个付费用户（年卡¥268）：
- 推荐分成：20 × ¥268 × 10% = ¥536
- 方案采纳奖金（假设采纳5条）：¥200×3 + ¥500×2 = ¥1600
- 总计收益：¥2136/年

## 四、运作机制

### 4.1 会议制度

| 会议类型 | 频率 | 时间 | 形式 | 参与人 |
|----------|------|------|------|--------|
| 周例会 | 每周 | 周一 20:00-20:30 | 微信群语音 | 全体 |
| 月评审会 | 每月 | 月末周五 20:00-21:30 | 腾讯会议 | 全体 |
| 季度线下会 | 每季度 | 周末半天 | 线下聚餐+研讨 | 核心3-5人 |
| 年度盛典 | 每年 | 年底 | 线下年会 | 全体 |

### 4.2 周例会议程模板

```
1. 本周数据回顾（5分钟）
   - 新增用户/活跃/付费数据
   
2. 本周产品更新（5分钟）
   - 已上线功能回顾
   - 用户反馈摘要
   
3. 下周计划同步（5分钟）
   - 待开发功能预告
   - 需要专家支持的点
   
4. 开放讨论（15分钟）
   - 专家自由发言
   - 问题和建议收集
```

### 4.3 月评审会议程模板

```
1. 月度数据报告（10分钟）
   - 核心指标达成情况
   - 渠道效果分析
   
2. 产品路线图评审（20分钟）
   - 下季度功能规划
   - 专家投票确定优先级
   
3. 市场策略讨论（20分钟）
   - 竞品动态分享
   - 推广策略调整建议
   
4. 专家提案征集（20分钟）
   - 每位专家提交1-2条建议
   - 现场评审可行性
```

## 六、专家日常管理

### 6.1 档案管理

| 字段 | 说明 |
|------|------|
| 姓名/头像 | 用于产品展示 |
| 所属领域 | 产品/技术/运营/市场/教育 |
| 联系方式 | 微信/电话/邮箱 |
| 加入时间 | 专家入驻日期 |
| 参会记录 | 历次会议出席情况 |
| 建议记录 | 提交过的建议及采纳状态 |
| 收益记录 | 推荐分成+采纳奖金累计 |

### 6.2 激励机制

| 指标 | 考核标准 | 奖励 |
|------|----------|------|
| 会议出席率 | ≥80% | 年度优秀专家评选资格 |
| 建议质量 | 被采纳≥3条/季度 | 额外¥500奖金 |
| 推荐效果 | 推荐付费≥5人/季度 | 额外¥200奖金 |
| 影响力 | 在社群/平台推荐产品 | 按效果奖励 |

## 七、风险控制

| 风险 | 应对措施 |
|------|----------|
| 专家不参与 | 设定最低出席要求，连续3次缺席自动退出 |
| 专家提出负面评价 | 公开透明处理，纳入产品迭代 |
| 专家带走用户资源 | 合同中约定竞业条款 |
| 专家离职后仍挂名 | 每年重新签约确认 |
