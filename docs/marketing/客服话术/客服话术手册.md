## 二、常见问题标准回复

### 2.1 转录相关问题

**Q：转录速度慢/超时**
```
您好！转录超时通常由以下原因导致：

1. 音频过长（>10分钟）— 建议拆分成多段上传
2. 音频质量差（噪音大/口音重）— 建议使用清晰录音
3. 网络不稳定 — 建议切换Wi-Fi后重试

如仍无法解决，请提供：
· 音频文件大小和格式
· 报错截图
我们将为您紧急处理。
```

**Q：转录不准确**
```
您好！转录准确率约95%，以下情况可能影响准确度：

· 专业术语/人名：可在字幕编辑器手动修改
· 中英混合：中文部分可能被近似转录
· 连读弱读：AI可能分开识别

建议：使用耳机录制，环境安静，语速适中。
如需调整特定内容，可在App内直接编辑字幕。
```

### 2.2 跟读评分问题

**Q：评分不准确/偏低**
```
您好！AI评分基于发音准确度、流利度、完整度三个维度：

· 准确度（50%）：每个音素是否发对
· 流利度（30%）：语速是否自然、有无过多停顿
· 完整度（20%）：是否读全所有单词

建议：
1. 先多听原音频3-5遍，熟悉语音语调
2. 跟读时保持正常语速，不要过快
3. 重点练习标红的部分
4. 同一句子可多次尝试，取最高分

AI评分仅供参考，不能完全替代真人老师。
```

**Q：评分总是很低怎么办**
```
评分低不代表英语不好，可能原因是：

1. 设备问题：请使用耳机麦克风录制（手机外放环境影响大）
2. 环境噪音：请在安静环境下练习
3. 音频难度：建议选择与自己水平匹配的音频
4. 发音习惯：某些方言口音会影响评分准确度

建议从简单音频开始，逐步提升难度。
坚持练习2周，评分会有明显提升。
```

### 2.4 技术问题

**Q：App闪退/崩溃**
```
您好！请按以下步骤排查：

1. 重启App
2. 检查系统版本：iOS 15+ / Android 8+
3. 清除缓存：设置 → 存储 → 清除缓存
4. 卸载重装（数据云端同步，不会丢失）

如仍崩溃，请提供：
· 设备型号和系统版本
· 崩溃时的操作步骤
· 截图/录屏
我们将尽快修复。
```

**Q：离线功能不能用**
```
您好！离线功能使用前需下载模型：

1. 打开App → 设置 → 离线ASR
2. 点击「下载语音模型」（约73MB）
3. 等待下载完成（建议在Wi-Fi环境下）
4. 下载完成后即可离线使用

下载失败请检查：
· 网络是否稳定
· 存储空间是否充足（需要100MB以上）
· 是否在Wi-Fi环境下
```

## 三、投诉处理流程

```
用户投诉
    ↓
第1步：倾听+记录（不打断，记录关键信息）
    ↓
第2步：共情（"我理解您的感受..."）
    ↓
第3步：确认问题（复述用户描述的问题）
    ↓
第4步：给出方案（提供1-2个解决方案）
    ↓
第5步：执行解决（立即处理或承诺时限）
    ↓
第6步：跟进确认（24小时内确认问题解决）
    ↓
第7步：记录归档（写入客服工单系统）
```
