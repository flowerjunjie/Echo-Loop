# 🚨 灵犀AI英语听说 · 危机公关快速反应卡

> 版本：v2.0 · 2026年8月16日  
> 使用说明：危机发生时，按此卡快速决策，不超过30分钟完成响应

---

## 一、危机分级（30秒判断）

```
🔴 紧急（立即响应）  →  服务器宕机/数据泄露/大规模崩溃
🟠 严重（30分钟内）  →  社交媒体大量负面/媒体报道
🟡 预警（2小时内）   →  3人以上同类投诉/小规模负面
🟢 一般（24小时内）  →  单个用户投诉/差评
```

---

## 二、5分钟决策流程

### Step 1：确认事实（5分钟）
- [ ] 问题是什么？（具体现象）
- [ ] 影响范围多大？（多少用户受影响）
- [ ] 根本原因？（技术/运营/人为）
- [ ] 预计恢复时间？

### Step 2：决定行动（5分钟）
- [ ] 属于哪级危机？
- [ ] 需要对外公告吗？
- [ ] 需要给用户补偿吗？
- [ ] 需要向上级汇报吗？

### Step 3：执行响应（10分钟）
- [ ] 对内同步（团队群通知）
- [ ] 对外公告（官网/App内/社交媒体）
- [ ] 用户沟通（客服回复）

---

## 三、各场景快速响应模板

### 场景A：服务器宕机

**30秒内**：技术团队确认问题，估算恢复时间

**5分钟内**：内部通知（飞书/微信群）
```
🚨 服务器宕机告警
问题： transcription服务不可用
影响： 所有用户上传音频无法转录
预计恢复：30分钟
处理人：@技术负责人
```

**30分钟内**：对外公告
```
【系统维护通知】
尊敬的用户，我们遇到短暂的服务器问题，
技术团队正在紧急修复，预计30分钟内恢复。
给您带来的不便深表歉意。
灵犀AI英语听说 团队
```

**恢复后**：补偿方案
```
对于本次服务中断，我们为受影响的用户
赠送3天会员时长，将在24小时内发放。
感谢您的理解和支持。
```

---

### 场景B：大规模用户投诉

**识别标准**：同一问题投诉≥3人

**5分钟内**：汇总投诉内容，定位共性问题

**30分钟内**：对外回应
```
【关于用户反馈的说明】
我们已收到部分用户关于[问题描述]的反馈，
目前技术团队正在排查，预计在[时间]内给出解决方案。
如有紧急问题，请联系support@...
灵犀AI英语听说 团队
```

**24小时内**：问题解决+公告
```
【问题修复通知】
关于[问题]，我们已经完成修复。
感谢大家的反馈，帮助我们发现问题。
如有任何问题，欢迎随时联系我们。
```

---

### 场景C：社交媒体负面

**识别标准**：小红书/抖音/微博出现负面内容

**1小时内**：评估影响范围
- 阅读量/点赞量
- 是否有大V转发
- 评论区内是否有类似反馈

**2小时内**：决定是否回应
- 阅读量<1000：不主动回应，监测即可
- 阅读量1000-5000：私信联系作者，了解具体情况
- 阅读量>5000：公开发布官方说明

**官方说明模板**：
```
关于近期大家关注的[问题]，我们想说明一下：
[事实陈述]
[我们的态度]
[我们正在做的]
感谢大家的关注和监督。
```

---

### 场景D：数据安全问题

**识别标准**：疑似数据泄露/黑客攻击

**30分钟内**：启动应急响应
- 技术团队隔离受影响系统
- 保留所有日志证据
- 通知法务/合规

**24小时内**：用户通知
```
【安全通知】
我们检测到潜在的安全风险，
已采取以下措施保护您的数据安全：
1. [措施1]
2. [措施2]
3. [措施3]
建议您[修改密码/检查账号]。
如有疑问请联系：support@...
```

## 四、禁忌行为（务必避免）

❌ 删除负面评论（激化矛盾）
❌ 在公开场合攻击用户（扩大争议）
❌ 长时间不回应（显得傲慢）
❌ 内部争论公开化（显得不专业）
❌ 推卸责任（失去信任）
❌ 撒谎或隐瞒（一旦被发现后果更严重）

---

## 五、响应原则

```
速度第一：危机发生后越快响应越好
真诚道歉：不推诿，不找借口
统一口径：所有对外信息保持一致
持续更新：定期向用户通报进展
```

**回复公式**：
```
共情 + 承认 + 方案 + 承诺 + 联系方式
```

**示例**：
```
「非常理解您的 frustration（共情）
是我们产品的问题导致您体验不佳（承认）
我们已经定位到问题，正在紧急修复（方案）
预计2小时内恢复，恢复后为您延长7天会员（承诺）
如有任何问题请联系：support@...（联系方式）」
```
