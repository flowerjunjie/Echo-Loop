## 二、指标详细定义

### 2.1 用户指标

#### DAU（日活跃用户）
**定义**：当日至少有1次打开App行为的独立用户数  
**计算方式**：去重统计当日所有登录用户的打开事件  
**注意**：同一用户多设备登录只算1个DAU  
**数据来源**：PostHog → Events → app_open  
**上报时机**：用户打开App时

#### MAU（月活跃用户）
**定义**：当月至少有1次打开App的独立用户数  
**计算方式**：去重统计当月所有登录用户的打开事件  
**注意**：自然月统计（1号~月底）

#### 新增用户
**定义**：首次注册并登录的独立用户  
**计算方式**：数据库中 created_at 为当日且 userId 首次出现  
**注意**：删除后重新注册算新用户

#### 付费用户
**定义**：当月有成功支付记录的用户  
**计算方式**：RevenueCat 中 status=active 或 trial_started 的用户  
**注意**：免费试用也算付费用户（转化成功）

---

### 2.2 留存指标

#### D1留存率
**定义**：今日新增用户中，明天仍然活跃的比例  
**公式**：D1留存率 = D1活跃用户数 / D0新增用户数 × 100%  
**目标**：≥60%  
**检查**：PostHog → Retention → Cohort D1

#### D7留存率
**定义**：今日新增用户中，7天后仍然活跃的比例  
**公式**：D7留存率 = D7活跃用户数 / D0新增用户数 × 100%  
**目标**：≥40%（Month 1）→ 50%（Month 6）  
**检查**：PostHog → Retention → Cohort D7

#### D30留存率
**定义**：今日新增用户中，30天后仍然活跃的比例  
**公式**：D30留存率 = D30活跃用户数 / D0新增用户数 × 100%  
**目标**：≥20%  
**检查**：PostHog → Retention → Cohort D30

---

### 2.3 收入指标

#### 月收入
**定义**：当月所有订阅收入之和  
**公式**：月收入 = Σ(当月所有成功支付金额)  
**数据来源**：RevenueCat Dashboard → Reports  
**注意**：包含月卡和年卡（年卡按12个月分摊到每个月）

#### ARPU（每用户平均收入）
**定义**：总收入 / 付费用户数  
**公式**：ARPU = 月收入 / 月付费用户数  
**目标**：≥¥268/年（即¥22.3/月）  
**注意**：仅计算当月有付费行为的用户

#### ARPPU（每付费用户平均收入）
**定义**：总收入 / 付费用户数  
**公式**：ARPPU = 月收入 / 月付费用户数  
**与ARPU区别**：ARPU除以总活跃用户，ARPPU只除以付费用户  
**目标**：≥¥28/月

#### LTV（用户生命周期价值）
**定义**：一个用户在整个使用周期内贡献的总收入  
**简化公式**：LTV = ARPPU × 平均使用月数  
**目标**：≥¥100  
**注意**：实际计算需要追踪 cohort 数据

---

### 2.4 转化指标

#### 付费转化率
**定义**：活跃用户中完成付费的比例  
**公式**：付费转化率 = 付费用户数 / 活跃用户数 × 100%  
**目标**：≥5%  
**细分**：
- 免费→付费：从免费版升级到会员
- 试用→付费：从试用版升级到正式会员

#### 漏斗转化率
**定义**：各关键节点之间的转化率  
**核心漏斗**：
```
打开App → 注册 → 首次转录 → 首次跟读 → 关注Paywall → 付费
   100%       70%       60%        40%         20%        5%
```
**检查点**：
- 打开→注册：≥70%
- 注册→首次转录：≥60%
- 首次转录→首次跟读：≥40%
- 跟读→关注Paywall：≥20%
- Paywall→付费：≥5%

---

### 2.5 获取成本指标

#### CPA（Cost Per Acquisition）
**定义**：获取一个付费用户的平均成本  
**公式**：CPA = 推广费用 / 新增付费用户数  
**目标**：<¥30  
**注意**：如果是自然流量，CPA=¥0

#### CAC（Customer Acquisition Cost）
**定义**：获取一个新用户的平均成本（含免费+付费）  
**公式**：CAC = 推广费用 / 新增用户数  
**目标**：<¥10

#### ROI（投资回报率）
**定义**：推广投入的回报效率  
**公式**：ROI = 月收入 / 推广费用  
**目标**：≥1.5（即每投入¥1，收回¥1.5）  
**注意**：需要至少1个月数据才能准确计算

---

### 2.6 产品指标

#### 转录成功率
**定义**：成功完成转录的音频比例  
**公式**：转录成功率 = 成功转录次数 / 总上传次数 × 100%  
**目标**：≥95%  
**失败原因分类**：
- 超时（>120s）：占比<5%
- 格式不支持：占比<2%
- 网络错误：占比<3%
- 其他：占比<5%

#### 崩溃率
**定义**：App崩溃次数占启动次数的比例  
**公式**：崩溃率 = 崩溃次数 / 启动次数 × 100%  
**目标**：<1%  
**数据来源**：Firebase Crashlytics / PostHog

#### NPS（净推荐值）
**定义**：用户愿意推荐产品的程度  
**调查方式**：App内弹窗，问"你有多大可能向朋友推荐灵犀AI？"（0-10分）  
**计算公式**：NPS = 推荐者%（9-10分） - 贬损者%（0-6分）  
**目标**：≥50  
**评价标准**：
- NPS > 50：优秀
- NPS 30-50：良好
- NPS < 30：需要改进

## 四、工具使用

### 4.1 PostHog
- **路径**：app.posthog.com
- **用途**：用户行为追踪、漏斗分析、留存分析
- **关键视图**：
  - Trends → 趋势分析
  - Funnels → 转化漏斗
  - Retention → 留存分析
  - Paths → 用户路径

### 4.2 RevenueCat
- **路径**：dashboard.revenuecat.com
- **用途**：订阅数据、收入分析、渠道归因
- **关键视图**：
  - Reports → MRR/ARR
  - Subscriptions → 订阅详情
  - Customers → 客户列表

### 4.3 Firebase
- **路径**：console.firebase.google.com
- **用途**：崩溃分析、性能监控
- **关键视图**：
  - Crashlytics → 崩溃列表
  - Performance → 加载时间

### 4.4 服务器日志
- **路径**：`tail -f /tmp/echo-transcribe.log`
- **用途**：转录成功率、服务器健康
- **关键命令**：
  ```bash
  # 查看今日转录统计
  grep "$(date +%Y-%m-%d)" /tmp/echo-transcribe.log | wc -l
  
  # 查看失败原因
  grep "FAIL" /tmp/echo-transcribe.log | awk '{print $NF}' | sort | uniq -c
  ```
