> 版本：v2.0 · 2026年8月16日  
> 分层模型：RFM + 行为标签双维度

---

## 一、用户分层体系

### 1.1 分层维度

**维度一：价值分层（RFM模型）**
- R（Recency）：最近一次使用距离今天的天数
- F（Frequency）：近30天使用频次
- M（Monetary）：累计消费金额

**维度二：行为分层**
- 功能偏好：转录型 / 跟读型 / 解析型
- 学习阶段：入门 / 进阶 / 高级
- 来源渠道：朋友圈 / 小红书 / 抖音 / 推荐

### 1.2 分层标准

| 层级 | R（天） | F（次/30天） | M（元） | 占比目标 |
|------|---------|-------------|---------|----------|
| 高价值用户 | ≤3 | ≥15 | ≥268 | 5% |
| 活跃用户 | ≤7 | ≥8 | 0-268 | 15% |
| 普通用户 | ≤14 | ≥3 | 0 | 30% |
| 沉默用户 | 15-30 | 0-2 | 0 | 30% |
| 流失用户 | >30 | 0 | 0 | 20% |

## 二、各层级运营策略

### 2.1 高价值用户（VIP）

**特征**：付费会员 + 高频使用 + 近期活跃

**运营目标**：提升续费率、促进转介绍

**触达方式**：
| 方式 | 频率 | 内容 |
|------|------|------|
| 专属客服 | 按需 | 快速响应，优先处理 |
| 内测邀请 | 新功能上线前 | 优先体验、收集反馈 |
| 生日祝福 | 每年1次 | 会员生日当天推送祝福+小礼品 |
| 年度总结 | 每年1次 | 生成学习报告+成就徽章 |

**激励策略**：
- 续费优惠：老用户续费享8折
- 推荐奖励：每推荐1人额外送14天会员
- 专属内容：每月1篇VIP专属学习材料

---

### 2.2 活跃用户（Potential）

**特征**：未付费但高频使用

**运营目标**：转化为付费用户

**触达方式**：
| 方式 | 时机 | 内容 |
|------|------|------|
| 功能触发推送 | 试用额度即将耗尽前3天 | 「你的AI功能快用完啦，升级解锁无限使用」 |
| 学习里程碑 | 完成第10/50/100次跟读 | 「你已经跟读了XX次，升级解锁更多功能」 |
| 限时优惠 | 每月月初/大促 | 「首月特惠¥19.9，仅限新用户」 |
| 社交证明 | 每周五 | 「你的同学XXX已经连续打卡7天了」 |

**转化策略**：
```
触发付费场景：
1. AI功能额度耗尽 → 弹订阅提醒
2. 跟读评分达到90分 → 弹「解锁更多音色」
3. 连续学习7天 → 弹「升级会员解锁离线功能」
4. 每周学习报告 → 弹「会员专享详细数据分析」
```

---

### 2.3 普通用户（Active Free）

**特征**：偶尔使用，未付费

**运营目标**：提升活跃度，培养使用习惯

**触达方式**：
| 方式 | 频率 | 内容 |
|------|------|------|
| 每日推送 | 1次/天 | 学习提醒+今日推荐材料 |
| 每周报告 | 1次/周 | 「本周学习总结+下周目标」 |
| 社群邀请 | 按需 | 邀请进入打卡群 |

**激活策略**：
- 推送最佳时间：早上8:00 / 中午12:00 / 晚上20:00
- 推送内容：个性化推荐（根据用户历史学习记录）
- 减少推送：连续3天未打开则停止推送，改为每周1次

---

### 2.4 沉默用户（At Risk）

**特征**：超过7天未活跃

**运营目标**：召回，恢复使用

**触达方式**：
| 方式 | 沉默天数 | 内容 |
|------|----------|------|
| App推送 | 7天 | 「好久不见！今日推荐材料已更新」 |
| 短信 | 14天 | 「你的学习进度已保存，回来继续」 |
| 邮件 | 21天 | 「专属回归福利：7天会员」 |
| 电话 | 30天 | 「我们还等你回来学习」 |

**召回策略**：
- 提供「学习进度恢复」功能（让用户感觉数据还在）
- 赠送限时会员（降低回归门槛）
- 发送个性化内容（「你之前学的XX内容有新更新」）

---

### 2.5 流失用户（Churned）

**特征**：超过30天未活跃

**运营目标**：二次激活 or 放弃

**触达方式**：
| 方式 | 流失时间 | 内容 |
|------|----------|------|
| 邮件 | 30天 | 「我们想你了」 |
| 短信 | 60天 | 「限时回归优惠」 |
| 社交媒体广告 | 90天 | 定向广告投放 |
| 放弃 | 180天 | 不再主动触达 |

**二次激活策略**：
- 新功能提醒：「我们上线了XX新功能，你可能感兴趣」
- 重大更新提醒：「版本大更新，体验全面提升」
- 限时回归优惠：「回归用户专享30天会员」

## 四、自动化营销规则

### 4.1 触发式推送规则

| 触发条件 | 延迟 | 推送渠道 | 内容模板 |
|----------|------|----------|----------|
| 注册后未登录 | 1天 | App推送 | 「还没有开始学习？点击开始」 |
| 首次转录完成 | 即时 | App推送 | 「恭喜！试试跟读练习吧」 |
| 跟读≥5次 | 7天 | 无 | 自动打标「repeat_frequent」 |
| 试用额度耗尽 | 2小时 | App弹窗 | 「AI功能即将到期，升级解锁」 |
| 连续3天未登录 | 1天 | App推送 | 「想你了，今天来练几句？」 |
| 订阅到期前7天 | 提前7天 | App推送+短信 | 「会员即将到期，续费享优惠」 |
| 生日 | 当天 | 专属推送 | 「生日快乐！送你7天会员」 |

| 层级 | 推送频率 | 触达渠道 |

| 高价值 | 每周1次 | 专属客服+推送 |
| 活跃 | 每日1次 | 推送+社群 |
| 普通 | 每周2次 | 推送 |
