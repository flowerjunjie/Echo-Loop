## 二、群规模设计

```
第一批种子群（50人）
├── 学员群（40人）：日常学习打卡+交流
└── VIP群（10人）：核心用户+KOC，优先内测新功能
```

**进群门槛**：
- 已在APP内注册过账号
- 完成至少1次跟读练习
- 通过邀请码/审核入群（保证质量）
