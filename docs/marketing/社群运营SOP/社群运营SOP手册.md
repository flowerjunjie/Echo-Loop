## 一、社群架构

### 1.1 群体系设计

```
灵犀AI英语学习交流群（主群，100人）
├── 打卡小组A（30人，入门级）
├── 打卡小组B（30人，进阶级）
└── 打卡小组C（30人，高级）

VIP会员群（付费用户，不限人数）
├── 每周分享会
├── 专属答疑
└── 新功能内测
```

### 1.2 群规（入群即告知）

```
【灵犀AI英语学习交流群规则】

1️⃣ 禁止广告：任何商业推广先私聊管理员
2️⃣ 鼓励打卡：每日分享学习截图+心得
3️⃣ 互助学习：积极回答问题，互相鼓励
4️⃣ 隐私保护：不转发群内学习内容到外群
5️⃣ 违规处理：违反群规首次警告，二次移出

🎁 打卡奖励：
· 连续7天：+7天会员
· 连续30天：+30天会员
· 月度优秀学员：额外奖励
```

## 二、每日运营节奏

### 2.1 早间运营（09:00-09:30）

| 时间 | 动作 | 话术模板 |
|------|------|----------|
| 09:00 | 发布早安+今日主题 | 「☀️ 早安！今日学习主题：[主题名]」 |
| 09:05 | 发布今日推荐材料 | 「📚 今天推荐材料：[材料名+链接]」 |
| 09:10 | 发起互动话题 | 「💬 今日话题：你最近在哪方面遇到困难了？」 |

**早安模板库**：
