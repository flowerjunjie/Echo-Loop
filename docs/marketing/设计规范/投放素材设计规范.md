## 二、各平台素材规格

### 2.1 朋友圈广告

**规格**：
- 尺寸：1080×1080（正方形）或 1080×1440（竖版）
- 格式：JPG / PNG
- 大小：≤5MB
- 文案上限：80字（标题）+ 200字（正文）

**设计要点**：
- 首屏3秒传达核心价值
- 产品截图占画面60%以上
- CTA按钮用金色，醒目
- 底部加品牌Logo+下载引导

**文案模板**：
```
[主标题] 30秒生成英语字幕
[副标题] AI跟读评分+句子解析
[痛点] 听力总听不懂？跟读练了无数遍还是找不到感觉？
[利益点] 上传音频→自动生成字幕→逐句跟读→AI评分
[CTA] 免费下载 → [按钮]
```

---

### 2.2 小红书图文

**规格**：
- 尺寸：1242×1660（3:4比例最佳）
- 格式：JPG / PNG
- 大小：≤10MB
- 封面：必须高清，带大标题文字

**封面设计规范**：
```
┌─────────────────────┐
│  [产品截图/人物场景]  │
│                     │
│   大字标题（2-4行）   │
│   如：30秒出字幕     │
│       太狠了         │
│                     │
│  [小字说明/品牌标]   │
└─────────────────────┘
```

**标题规范**：
- 字数：15-25字
- 必须包含数字或符号（⚡💡🎯等）
- 前5个字决定点击率

**正文规范**：
- 字数：300-800字
- 分段清晰，每段不超过3行
- 适当使用emoji增加可读性
- 文末必有CTA和话题标签

---

### 2.3 抖音短视频

**规格**：
- 尺寸：1080×1920（9:16竖版）
- 格式：MP4
- 时长：15-60秒（15秒效果最佳）
- 大小：≤100MB

**视频设计规范**：
```
┌─────────────────────┐
│                     │
│    [视频主体区域]    │  安全区：上下各留10%
│    （居中）         │     避免被UI遮挡
│                     │
├─────────────────────┤
│  [底部信息区]       │  避免覆盖文案
│  文案/话题标签      │
└─────────────────────┘
```

**开场3秒规范**：
- 必须有悬念钩子（问题/对比/反差）
- 大字标题覆盖画面
- 音乐节奏感强

**字幕规范**：
- 字体：思源黑体 Bold
- 大小：≥48pt
- 颜色：白色+黑色描边
- 位置：画面中下部

## 三、文案规范

### 3.1 标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | 数字+结果 | 「30秒出字幕，准确率95%」 |
| 痛点型 | 痛点+解决方案 | 「听力总听不懂？因为这个」 |
| 对比型 | 传统vs新方案 | 「人工转录vs AI转录，差距有多大」 |
| 场景型 | 场景+效果 | 「用这个方法，3个月口语翻倍」 |
| 社交证明型 | 用户数+评价 | 「1000+用户推荐的学习神器」 |

### 3.2 CTA规范

| 平台 | 推荐CTA |
|------|---------|
| 朋友圈 | 「免费下载」「立即体验」 |
| 小红书 | 「评论区见」「戳链接」 |
| 抖音 | 「下载地址在评论区」 |
| 公众号 | 「点击阅读原文」「扫码下载」 |

### 3.3 话题标签规范

**小红书**：5-8个，混合大中小标签
```
#英语学习 #口语练习 #AI工具 #学习APP #四六级 #考研 #雅思
```

**抖音**：3-5个，聚焦核心关键词
```
#英语学习 #英语口语 #AI学习 #学习神器
```
