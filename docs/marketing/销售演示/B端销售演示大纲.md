## 演示流程总览

```
开场（2分钟）→ 痛点共鸣（3分钟）→ 产品演示（8分钟）
```

---

## 第一部分：开场（2分钟）

**目标**：建立信任，引起注意

**话术**：
```
"王老师您好，感谢您抽出时间。
在开始之前，我想先请教一个问题：
咱们学校的学生在课后口语练习这块，
老师是怎么监督的？
"
```

**倾听要点**：
- 记录学校现状（有/无课后作业检查机制）
- 找到痛点（学生不爱练、老师没空改、家长不管）
- 顺势引入："这正是我们今天想解决的问题"

---

## 第二部分：痛点共鸣（3分钟）

**三问锁定痛点**：

| 问题 | 对应痛点 | 预期回答 |
|------|----------|----------|
| "学生课后口语练习，老师能听到每个人的发音吗？" | 无法逐一纠正 | "听不过来/没时间" |
| "学生回家练不练，老师怎么知道？" | 缺乏监督机制 | "靠自觉/基本不走心" |
| "英语听力材料从哪来？学生有坚持练吗？" | 材料获取难+坚持难 | "教材固定/学生嫌枯燥" |

**总结痛点**：
```
"所以三个核心问题：
1️⃣ 老师没法逐一纠正发音
2️⃣ 课后练习没有监督机制
3️⃣ 学生练习材料匮乏、坚持不下去

我们做的灵犀AI英语听说，就是为了解决这三个问题。"
```

---

## 第三部分：产品演示（8分钟）⭐核心

### 演示一：音频转录（2分钟）

**操作步骤**：
1. 打开App → 点击「添加音频」
2. 选择一段英语听力音频（建议用学校教材配套音频）
3. 等待30秒 → 展示字幕生成结果
4. 点击句子 → 展示逐句播放功能

**话术**：
```
"这是咱们用的教材听力原文，
上传后30秒自动生成字幕，
准确率95%以上。
学生可以对照字幕听，也可以看着字幕跟读。"
```

### 演示二：跟读练习（3分钟）⭐最亮点

**操作步骤**：
1. 点击任意句子 → 进入跟读界面
2. 点击麦克风 → 开始跟读
3. 跟读完成 → 展示AI评分（准确度/流利度/完整度）
4. 展示标红的发音错误部分
5. 重新跟读 → 展示分数提升

**话术**：
```
"这是核心功能——AI跟读评分。
学生对着句子读，AI即时打分，
标红部分就是发音有问题的地方。
您看，我第一次62分，
听了几遍原音频再读，85分。
学生自己就能看到进步，
不用等老师批改。"
```

### 演示三：AI句子解析（2分钟）

**操作步骤**：
1. 点击句子 → 展示翻译+语法分析
2. 展示意群切分
3. 展示TTS语音播放

**话术**：
```
"这个句子学生看不懂？
AI一键翻译，还会分析语法结构，
哪些是主谓宾、哪些是修饰成分，一目了然。
还能用标准发音播放，辅助学生模仿。"
```

### 演示四：教师后台（1分钟）

**操作步骤**：
1. 切换到教师/机构账号
2. 展示班级学生列表
3. 展示学生跟读成绩统计
4. 展示班级整体报告

**话术**：
```
"老师端可以看到：
· 每个学生的跟读成绩
· 班级整体正确率分布
· 哪些句子大家普遍读不好

这样老师备课就能有针对性，
不用从头讲到尾。"
```
