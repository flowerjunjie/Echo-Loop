### 动作二：发出破冰消息 + 正式邀请函（本周内）

**节奏**：
- Day 1（今天）：发出3条破冰消息
- Day 2-3：跟进回复，发送正式版邀请函
- Day 4-5：与确认意向者1对1沟通

**文案直接使用**：`docs/operations/专家团/邀请函模板.md` 中的微信私信版。

**每日目标**：
- 周一-周三：每天至少2条破冰消息
- 周四-周五：跟进已读未回，补发第二轮

---

### 动作三：同步更新记录（贯穿本周）

每次联系后更新 `候选人名单模板.csv` 中的状态字段：

| 状态值 | 含义 |
|--------|------|
| 待联系 | 尚未接触 |
| 已联系-待回复 | 消息已发，等回复 |
| 已读-待回复 | 对方已读，未回复 |
| 已沟通-意向强 | 电话/语音沟通过，明确想加入 |
| 已沟通-意向弱 | 沟通过，犹豫中 |
| 已婉拒 | 明确拒绝 |
| 已确认加入 | 同意加入专家团 |
