# 首次专家会议议程

> 版本：v1.0 · 2026-08-27
> 建议时长：45-60分钟
> 形式：微信群语音 或 腾讯会议

---

## 会前准备（会议前3天完成）

### 组织者 Checklist

- [ ] 确认所有专家能参会（提前1天再确认一次）
- [ ] 准备产品介绍PPT（10页以内）
- [ ] 准备产品数据（DAU、留存、功能使用率等）
- [ ] 准备会议室链接/群语音测试
- [ ] 打印/准备会议纪要模板
- [ ] 提前把会议议程发到群里

### 资料清单

1. 产品介绍PPT
2. 当前产品数据截图
3. 用户反馈摘要（3-5条真实反馈）
4. 产品路线图（未来3个月计划）
5. 会议纪要模板

---

## 会议议程

### 第一部分：开场与介绍（5分钟）

**主持人**：[联系人姓名]

1. 自我介绍（1分钟）
   - 我是谁，做什么的
   - 为什么做灵犀AI英语听说

2. 欢迎专家入群（2分钟）
   - 感谢大家的时间
   - 简要说明会议目标

3. 专家轮流自我介绍（2分钟）
   - 每人30秒：姓名+领域+一句话自我介绍

---

### 第二部分：产品介绍（10分钟）

**演示人**：产品负责人

1. 产品定位（2分钟）
   - 我们解决什么问题
   - 目标用户是谁
   - 目前的市场阶段

2. 核心功能演示（5分钟）
   - 音频上传→转录→跟读练习 完整流程
   - 展示真实使用场景
   - 突出差异化优势（离线使用、准确率、价格）

3. 当前数据（3分钟）
   - 注册用户数
   - 日/周活跃
   - 付费转化
   - 用户好评截图

---

### 第三部分：产品方向与规划（10分钟）

1. 产品路线图（5分钟）
   - 已完成的功能
   - 正在开发的功能
   - 未来3个月计划

2. 当前面临的挑战（5分钟）
   - 坦诚说出目前的困惑和难点
   - 例如：获客成本高、用户留存有待提升、功能优先级难定等
   - 引导专家提出看法

---

### 第四部分：专家自由讨论（15分钟）

**主持人引导问题**：

1. "从您的专业角度看，我们目前最大的问题可能是什么？"
2. "您觉得我们的目标用户找对了吗？"
3. "如果让您给产品提一条最重要的改进建议，会是什么？"
4. "您身边有没有可能试用我们的产品的人？"
5. "对于我们的推广渠道，您有什么建议？"

**主持人注意事项**：
- 不要打断专家发言
- 对每条建议做简要复述确认理解
- 记录关键词，不做逐字记录（详细记录会后整理）
- 控制时间，确保每人都有发言机会

---

### 第五部分：机制说明与收尾（5分钟）

1. 说明专家团运作机制（3分钟）
   - 周例会：每周一晚8点，微信群语音，30分钟
   - 月评审会：每月最后一个周五晚，腾讯会议，1.5小时
   - 随时：微信私聊，有问题随时沟通
   - 权益说明回顾：终身会员+10%分成+采纳奖金

2. 收集下次会议议题（1分钟）
   - "大家有什么想聊的，下次会议可以安排"

3. 宣布散会（1分钟）
   - 感谢大家的时间
   - 预告下次会议时间

## 会后行动项

**格式模板**：

```
会议日期：2026-XX-XX
参会人员：[专家姓名1]、[专家姓名2]、...
主持人：[姓名]
记录人：[姓名]

一、会议要点
1. ...
2. ...

二、专家建议
| 专家 | 建议内容 | 优先级 |
|------|---------|--------|
| | | |

三、待跟进事项
| 事项 | 负责人 | 截止时间 |
|------|--------|---------|
| | | |

四、下次会议
时间：2026-XX-XX 20:00
议题预告：...
```

### 会后48小时内

- [ ] 把会议纪要发到专家群
- [ ] 逐条回复专家建议（采纳/暂缓/拒绝+理由）
- [ ] 更新每位专家的档案卡
- [ ] 把采纳的建议纳入产品需求池
- [ ] 如有需要，单独约专家深度沟通

## 附录：常见问题应对

| 情况 | 应对策略 |
|------|---------|
| 专家沉默不说话 | 点名提问，给出具体问题而非开放问题 |
| 专家提出的建议不切实际 | 感谢后说明当前资源限制，探讨可行替代方案 |
| 专家提负面评价 | 坦诚接受，记录并承诺评估，不当场反驳 |
| 专家问数据敏感问题 | 给区间范围，不说精确数字 |
| 会议超时 | 提前提醒时间，剩余议题放到下次或私聊 |
