## 一、产品基础信息

### 1.1 产品定位

**一句话介绍**：30秒，让每段英语音频变成你的私人外教。

**核心能力**：
- 音频转录：上传任意英语音频，AI 30秒出字幕，准确率 95%+
- AI 跟读评分：逐句跟读，即时打分，标红发音错误
- 智能解析：翻译 + 语法分析 + 意群切分
- 离线使用：下载模型后无需联网

**平台**：iOS · Android · Web 三端同步

## 三、激活码使用说明

### 3.1 激活码格式

- 长度：14位大写字母+数字（如 `JVT34NXKPX97`）
- 有效期：12个月（生成时指定）
- 座位数：默认 1 个账号额度（可批量生成）

### 3.2 生成激活码（管理员操作）

```bash
# 生成激活码
curl -X POST http://38.55.146.160:3003/api/v1/activate/generate \
  -H "X-Admin-Key: el-admin-c491bbd5a9c5782c3435223f604e943a" \
  -H "Content-Type: application/json" \
  -d '{"count":10}'

# 查看激活码列表
curl http://38.55.146.160:3003/api/v1/activate/my-codes \
  -H "X-Admin-Key: el-admin-c491bbd5a9c5782c3435223f604e943a"

# 查看统计
curl http://38.55.146.160:3003/api/v1/activate/stats \
  -H "X-Admin-Key: el-admin-c491bbd5a9c5782c3435223f604e943a"
```

### 3.3 激活码分发流程

```
生成激活码 → 分配给机构 → 发给学员 → 学员在App内输入激活 → 完成
```
