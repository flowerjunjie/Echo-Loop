## 迭代1：产品功能打磨（Week 1）

### 1.1 核心Bug修复（P0）

#### 转录超时问题
**问题描述**：faster-whisper 转录耗时210秒，用户等待过久导致放弃

**解决方案**：
```bash
# 服务器端优化
pip install faster-whisper==1.2.1

# Whisper tiny 模型配置（CPU推理，~73MB）
model = WhisperModel(
    model_size="tiny",
    device="cpu",
    compute_type="int8"
)

# 预期效果：210s → 35s（6倍提升）
```

**验收标准**：
- 平均转录时间 ≤ 35秒
- 转录成功率 ≥ 95%
- 支持中英混合音频

#### 离线ASR闪退问题
**问题描述**：Android结束录音后，sherpa-onnx Silero VAD native推理崩溃

**排查步骤**：
1. 真机连接：`adb logcat -d > crash.log`
2. 查看tombstone：`adb shell run-as com.echoloop cat /data/tombstones/tombstone_XX`
3. 定位崩溃native frame

**临时方案**：
- 自适应跳过VAD检测（减少native调用）
- AudioRecord串行化处理（避免多线程冲突）
- CPU provider降级兜底

### 2.3 FAQ文档

```markdown
## Q1：转录成功率如何？
A：支持中英文混合，准确率约95%。嘈杂环境可能影响结果，建议使用耳机麦克风。

## Q2：离线ASR需要下载什么？
A：首次使用时需在设置中下载语音识别模型（约73MB），下载后可离线使用。

## Q3：TTS音色有哪些？
A：提供系统语音（免费）和灵犀AI语音（需会员），包含男女声多种音色。

## Q4：订阅后可以退款吗？
A：iOS/Android平台遵循各自应用商店的退款政策。 web渠道支持7天内无理由退款。

## Q5：激活码如何使用？
A：在设置页点击「激活码兑换」，输入8位激活码即可解锁会员权益。

## Q6：数据安全吗？
A：音频文件仅用于转录，不上传到第三方服务器。所有数据加密存储。

## Q7：支持哪些音频格式？
A：支持MP3、WAV、M4A、AAC等常见格式，最大支持100MB/文件。
```
